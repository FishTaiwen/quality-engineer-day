# 劇透：支線與隱藏結局

建議先自行玩一輪。事件隨機插單不影響三條支線的固定節點。

## 三支線一起完成

- 08:30 選「隔離混箱，建立箱號對照」。
- 09:10 選「開 NCR / CAR，要求原因與改善證據」。
- 10:40 選「核對基準與加工紀錄，補上量測依據」。
- 12:05 選「先吃飯，指定急件窗口與回覆時間」。
- 13:10 選「保留批次，補回序號與測試關聯」。
- 14:10 選隱藏的「封存版本履歷，核對切換點」，或一般「核對 EC 履歷，隔離舊版圖面」。
- 15:10 選「整理證據、回覆節點，指定接手窗口」。
- 17:10 選「補齊保護與標籤，留下改善追蹤」。
- 18:00 選隱藏的「確認窗口接手，關閉通知並離場」。

以上完成三支線，同時得到隱藏結局「下班是一個完整的句子」。其他事件選項不影響上述支線，但會影響指標。

## 隱藏結局：版本漂移

完成追溯支線前兩階段，14:10 選「封存版本履歷，核對切換點」。18:00 選一般交接離場（不要選界線隱藏離場），或進入加班；完成時獲得「不是你記錯，是版本在漂移」。若兩種隱藏條件同時達成，界線結局優先。

若 14:10 只選一般核對，追溯仍可完成。進入夜班後 21:40 會出現「封存完整履歷，附上版本時間線」，作為備份觸發方式。

## 其他結局

沒有隱藏條件時依序判定：品質低於 45 → 放行很快，回來也很快；壓力至少 80 或加班至少 200 分 → 明天見，今天還沒結束；品質至少 80 且信用至少 65 → 文件都在，人還在；其餘 → 普通的一天，異常的一生。

想走夜班，18:00 選任何接電話/帶回家的選項。夜班有三起事件，最後一定結案。職能 SQE 與 CQE 因第二次指定事件取得永久資格；插單也可能使其他職能提早取得永久資格。

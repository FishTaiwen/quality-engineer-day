## 邊界與尚未驗證

- GitHub Pages 已備妥靜態結構與部署說明，但沒有實際建立儲存庫或發布。
- 真實 Android / iOS 裝置，以及 Firefox / Safari 尚未實機驗證；手機驗證是瀏覽器尺寸模擬。
- 內建瀏覽器的下載事件未回傳可檢查的落地檔案路徑；因此提供報告文字預覽與可複製內容作為替代。下載連結使用標準 Blob + download；一般外部瀏覽器實際下載仍需部署後確認。
- 停線分鐘與事件時鐘分離；加班分鐘是事件成本，與時鐘間隔不必一致，皆為敘事指標。
- 品質與信用會限制在 100，因此良好處置的後段可能顯示品質不變，這是上限生效，不是漏算。
- 「永久資格」限目前工作日，並非跨新局的職涯存檔；跨局只保留結局收藏。
- 未做真實製程判定、量測標準或實際現場安全驗證；這是虛構敘事遊戲。

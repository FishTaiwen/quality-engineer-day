# 品保工程師的一天

白天守品質，晚上守群組。以虛構台灣電子／液冷製造業情境為舞台的職場黑色幽默敘事遊戲。HTML / CSS / 原生 JavaScript，無套件、無後端、無外部資源。

## 馬上遊玩

直接以現代瀏覽器開啟 `index.html`。全部腳本使用一般 script，無模組跨來源限制，可離線開啟。建議使用最新版 Chrome、Edge、Firefox 或 Safari。每輪約 10–15 分鐘；可隨時關閉後回來。

若要本機伺服器預覽，在專案目錄執行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

開啟 http://127.0.0.1:4173 。遊戲自動保存在同一瀏覽器、同一來源的 localStorage；直接開啟檔案的存檔行為可能依瀏覽器不同。儲存受限時仍可遊玩與匯出紀錄。從檔案移至網站、換網址、換瀏覽器或清除資料不會攜帶原進度。

## 已完成的 MVP

- 12 個日班時段；選擇接下班電話後，另有 3 個完整夜間事件。
- 八件隨機事件，每輪抽兩件、不重複；以種子保留重現能力。
- 品質、壓力、信用、停線分鐘、加班分鐘，選項實際效果預覽與敘事後果。
- QE 起始，事件解鎖 IQC、SQE、PQE、IPQC、FQC、CQE、OQC；同職能累計處理兩起指定事件取得永久資格。
- 供應商改善、批號追溯、便當保衛戰三條連續支線；錯過節點會提示。
- 兩個隱藏事件、兩個隱藏結局，共六個可收藏結局。
- 自動存檔、保留結局收藏的重新開始、文字交接報告下載。
- 企業系統 × CSS 像素產線，桌機與手機適配；鍵盤焦點、減少動態效果、說明視窗。

永久資格僅在目前工作日有效；結局收藏可跨新局保留。遊戲讓每個工作日都重新體驗從 QE 被派任成多種職能的過程。

## GitHub Pages 靜態部署

1. 建立 GitHub 儲存庫，把**本專案資料夾內的檔案**放到儲存庫根目錄（根目錄必須有 `index.html`）。
2. 推送至 `main`。
3. 儲存庫 Settings → Pages → Build and deployment 選擇 Deploy from a branch。
4. Branch 選 `main`，Folder 選 `/ (root)`，儲存。
5. 等待 Pages 完成，開啟 Pages 顯示的網址。

全部網址採相對路徑，支援 `https://<帳號>.github.io/<儲存庫>/` 子目錄。附 `.nojekyll`，不需建置。沒有替使用者建立儲存庫或實際上線。

## 結構

```text
index.html                頁面與無障礙結構
css/style.css             響應式企業系統與像素場景
js/data.js                職能、支線、日班、隨機、夜班、結局資料
js/engine.js              純規則引擎、種子亂數、支線、數值與存檔驗證
js/app.js                 DOM、自動存檔、說明、收藏與報告下載
docs/GAME_DESIGN.md        完整設計、主線與擴充願景
docs/ARCHITECTURE.md       資料契約與後續擴充方式
docs/WALKTHROUGH.md        劇透：支線、隱藏事件與結局條件
docs/QA.md                驗證紀錄與限制
tests/engine.test.cjs      無依賴規則測試
.nojekyll                 GitHub Pages 靜態檔案標記
```

## 驗證

安裝 Node.js 後，在專案目錄執行：

```sh
node tests/engine.test.cjs
```

涵蓋 4,000 個完整模擬工作日、六種結局可達成、三支線完成、八職能解鎖、永久資格、夜班、種子可重現、數值範圍、存檔驗證及重複提交防護。實際瀏覽器檢查與已知限制見 `docs/QA.md`。
